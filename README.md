# marabosing-spa

Landing page da Mara Bösing - Beleza e Spa.

## Conteúdo

- `Mara Bösing - Beleza & Spa.html`: página responsiva da landing page.
- `assets-clean/`: imagens utilizadas pela página.
- `Mara Bösing - Apresentação.pdf`: versão da página formatada para apresentação.

## Visualização local

Abra `Mara Bösing - Beleza & Spa.html` diretamente no navegador ou sirva a pasta com um servidor HTTP local.
